시공사에게 받은 견적서 파일을 화면 아무 곳에나 마우스로 끌어다 놓기(Drag & Drop) 하거나, 좌측 상단의 [📂 견적서 파일 첨부] 버튼을 클릭하여 선택합니다.

✔ 100% 로컬 보안: 서버 전송 없이 브라우저 메모리 안에서 안전 처리 (유출 0%)

1단계: 견적서 화면 캡처

2단계: 검증기 화면에서 붙여넣기
