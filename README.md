## 🎨 UI/UX 및 디자인 아키텍처

1. **원스크린(One-Screen) 시야각 완성**:
   - 상단 보조 설명문구와 검색 옴니바를 과감히 정리하여, 1080p Full HD 및 노트북 화면에서 스크롤 0px로 16개 모든 핵심 서비스 카드가 한눈에 들어오는 쾌적한 뷰포트 유지.
2. **실시간 방문자 카운터 (`[👥 • 오늘 X명 | 누적 Y명]`)**:
   - 독립 VPS SQLite 백엔드(`chatbot.aisen.store/api/visitors`) 연동, 당일 IP/User-Agent 해시 기반 고유 방문자 중복 제거 집계 및 🟢 에메랄드 펄스 인디케이터 탑재.
3. **사이드바 최적화 (1열 단일 리스트 + 14px 볼드 + 쾌적한 행간)**:
   - 2열 배치의 글자 잘림 및 가로폭 압박을 방지하기 위해 **단일 1열 세로형** 유지.
   - 반복되던 `AI-SEN ` 접두어를 제거하여 핵심 명칭(`행정챗봇`, `계약`, `공사원가`, `엑셀수합`, `기안문` 등)으로 시인성 극대화.
   - 폰트 크기를 **14px 볼드**로 키우고 넉넉한 패딩(`px-3.5 py-2.5`)과 6px 슬림 스크롤바를 적용하여 극상의 가독성과 클릭 안정성 확보.
4. **포털 이용안내 설명서 전 탭 세로형 카드 (`lg:grid-cols-4`) 일원화**:
   - 가로형(2열)을 전면 배제하고 포털 메인 4×4 행과 1:1 대칭을 이루는 4대 분야 전 탭 1행 4열 세로형 카드로 통일.
   - 카드 헤더 타이포그래피 최적화(`text-[15px] sm:text-base font-black`, 뱃지 `whitespace-nowrap`)로 제목 줄바꿈 원천 차단 및 독립 `/guide` 라우트 `max-w-[1360px]` 동기화.
5. **Web MCP 테스터 (`chatbot.aisen.store/mcp`) 고시인성 원스크린 콘솔**:
   - 상단 헤더 및 5대 도구 탭 바 폰트 확대, 백엔드 Uvicorn self-call 이벤트 루프 데드락 비동기 스레드 풀 격리(`asyncio.to_thread`)로 지침서 RAG 초고속 실시간 답변 완결.
