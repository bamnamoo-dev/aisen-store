## 📖 프로젝트 개요

## 🚀 핵심 차별화: 데이터 파이프라인 & 중앙 통제

### 1. [공사원가 ➔ 계약 ➔ K-에듀파인 기안문] 원스톱 파이프라인
`AI-SEN 공사원가`에서 제비율 역산 감사가 완료되면, **[🧭 서울교육 계약나침반으로 연동]** 버튼 1클릭으로 확정 공사비와 공종, 공사명이 `AI-SEN 계약`으로 즉시 전달되어 수의계약 대상 판정 및 K-에듀파인 기안문 사유서가 10초 만에 자동 작성됩니다.

### 2. 중앙 집중형 요율 통제 체계 (`rates-config.json`)
조달청 간접공사비 제비율(2024~2026 다년도 보존)과 지방계약법 소액수의 한도액, 부가세율을 `public/data/rates-config.json` 단 한 곳에서 통합 관리합니다.

## 📦 AI-SEN 올인원 교육행정 MCP & Python Suite (`aisen-mcp` v2.0)

AI-SEN STORE의 핵심 연산 엔진을 외부 AI(Claude Desktop, Antigravity, Cursor 등) 및 일반 Python 코드에서 손쉽게 활용할 수 있는 표준 패키지입니다.

1. **`search_guidelines`**: 2026 지침서/법령/에듀파인 3-Tier RAG 하이브리드 검색
2. **`calculate_travel`**: 관내 및 **관외 2박 3일 복합 여비(일비/식비/숙박비/KTX 운임)** 정밀 정산 & 에듀파인 결재용 마크다운 표 생성
3. **`calculate_fuel`**: 오피넷 전국 실시간 유가 및 **카카오 모빌리티 실도로 경로 길찾기** 유류비 산출
4. **`find_forms`**: 75종 행정·민원 개방형 HWPX 서식 검색 및 다운로드 (2단계 스마트 폴백 내장)

> **네이티브 백엔드 1:1 벤치마크 검증**: 관내 11,500원 일치, 관외 390,000원 일치, 카카오 경로 1,280원 일치, 국고금 10원 절사 PASS 등 기존 엔진 대비 오차 0원(100% 일치) 확인 완료.
