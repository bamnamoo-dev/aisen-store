## 📥 표준 서식 및 감사결과 엑셀(.xlsx) 연동 규격

스마트 원가계산서 검증기 웹 인터페이스에서 다음 2대 표준 엑셀 문서를 실시간 생성 및 다운로드할 수 있습니다:

1. **[📥 표준 양식(.xlsx)] - 2026 조달청 표준 학교공사 수식형 서식**:
   - 실무자는 `공사기간(D2)`, `직접재료비(B6)`, `직접노무비(B9)`, `기계경비(B12)`만 입력.
   - 간접노무비, 4대보험, 산안비, 일반관리비, 이윤, 총도급액(10원 절사)까지 **살아있는 엑셀 수식(`cell.f`)**으로 자동 계산.
   - **실시간 법정 자가진단(E열)**: 30일 미만 공사 입력 시 건강/연금/요양 자동 0원 및 오류 경고, 산안비 2천만 미만 면제 자동 감지 내장.
   - 기재부 계약예규 제8조제2항 준수: 이윤 산출식에서 재료비(B8) 원천 배제.

2. **[📊 감사결과 엑셀(.xlsx)] - 감사결과 대차대조표**:
   - 3번 표준 서식의 22개 비목·행 체계를 1:1로 계승한 6열 대차대조표.
   - **수식 연동**: `B열(업체 제출액)` vs `C열(조달청 적정액)` ➔ `D열(삭감액: =B-C)` ➔ `E열(판정: =IF(D>10,...))`.
   - 시공업체 제출용 **공식 수정요청 통보문 요약** 자동 포함.
   - **한셀 & 엑셀 100% 호환**: 공공기관 표준 함수(`IF`, `SUM`, `ROUND`, `FLOOR`) 및 이중 주입(Dual Injection)으로 `#VALUE!` 에러 원천 차단.
